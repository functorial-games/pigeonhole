# Pigeonhole

A small game/research repository about the pigeonhole principle as a statement about maps, fibers, quotients, exactness, and the structures that grow out of those ideas.

The reading shelf is in [`books/`](books/README.md).

The current design direction is deliberately broader than a one-off "put pigeons in holes" puzzle: start with the concrete finite-set interaction, then reuse the same structural intuition for fibers, quotienting by equal images, exact sequences, double covers, and eventually spectral-sequence-like bookkeeping. The exact game interaction is not fixed yet.
