# Full-recall reading shelf

This directory keeps the reading behind the game close to the project.

## House rules

For each substantial source:

- keep a stable link to the original or an authoritative host;
- record redistribution status before mirroring a full text;
- if redistribution permission is not clear, keep the source link-only and write our own summary;
- recover the source bibliography when possible;
- explicitly thank the author and the people whose work appears in that bibliography;
- keep first-party historical notes from the project's author when they illuminate why a source was saved.

No unofficial commercial-book mirrors belong here.
