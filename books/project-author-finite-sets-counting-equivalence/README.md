## Counting as quotienting by everything except size

The “Do numbers exist?” post uses the idea associated with W. V. O. Quine that a counting number can be represented by an equivalence class of all finite sets having that cardinality.

Whether one adopts that ontology literally is less important here than the operation:

- start with many very different sets;
- forget everything except how many elements they contain;
- identify all sets with the same size.

That is quotienting by an equivalence relation.

The structure-preserving-map post makes the same point with the example of all sets of a fixed cardinality being equivalent **with respect to size**, though not necessarily with respect to any other property.

The Baez–Dolan post pushes on the distinction between equality and isomorphism/equivalence: the interesting mathematical statement is often not literal identity \(x=x\), but that two different-looking objects agree in a specified structural sense.

## Relation to pigeonhole

The pigeonhole principle is about more than raw numbers.

For a function
\[
f:A\to B,
\]
the numbers \(|A|\) and \(|B|\) constrain what kinds of maps are possible:

- \(|A|>|B|\) forbids injectivity;
- \(|A|<|B|\) forbids surjectivity;
- \(|A|=|B|\) makes injective, surjective and bijective equivalent for finite sets.

So cardinality is the first deliberately forgotten structure in the game: ignore every property of the objects except “how many source states?” and “how many target states?”

Then progressively restore structure in later levels.
